# Presentation Demo Walkthrough

This document outlines the exact steps to follow during the live presentation demo. Each section corresponds to a different presenter and user perspective.

---

## Sean — Admin User Flow

### Phase 1: Event Review & Calendar Membership Verification
*Demonstrates event viewing, editing notes, and calendar membership awareness*

1. Log in to account  
2. Click on **Today**  
3. Scroll to the **Presentation** event  
4. Click on the **Presentation** event  
5. Update Notes to say: *"Ethan brings the laptop"*  
6. Exit the event  
7. Click **View Calendars**  
8. Verify that **Ethan** is a member of the calendar  
9. Exit calendar view  

---

### Phase 2: Participating in a Poll
*Demonstrates member participation and real-time poll results*

10. Look at the **Polls** window  
11. Filter by **Active Polls**  
12. Open **"Nuggets Poll"**  
13. Vote to move the game to the **7th**  
    - Explain you don’t want a game on Valentine’s Day  
14. Notice and point out the poll results  

---

### Phase 3: Confirming Admin Permissions
*Demonstrates role-based permissions*

15. Say: *"I want to check if I'm an admin of the calendar to see if I can update the event."*  
16. Exit the poll  
17. Click **View Calendars**  
18. Select **Basketball – Wizards**  
19. Say: *"I'm an admin of this calendar, so I will change the date."*  

---

### Phase 4: Admin Event Modification
*Demonstrates admin-only event editing*

20. Click on **February 14th**  
21. Click on the **Pickup Game**  
22. Click **Edit Event**  
23. Change the date to **February 7th**  
24. Save the event  
25. Click on **February 7th** to confirm the event moved  
26. Log out  

---

## Ethan — Calendar Member User Flow

### Phase 1: Dashboard Search

1. Log in
2. Click on **February 14th** looking for the pickup game vs Wizards
3. Go back to **Month View**
4. Click on the **"Basketball – Wizards"** calendar to filter events
5. Click on the **"pickup"** tag to filter further
6. Click on **February 21st** and confirm it is not the correct game

### Phase 2: View Events Modal Search

7. Click the **View Events** button
8. Again select **"Basketball – Wizards"** and **"pickup"** filters
9. Say: *"I still can't find it, so…"*
10. Search **"Nuggets"** in the search bar
11. Click on the event

### Phase 3: Share the event with Ben

12. Say: *"I want to invite my friend Ben to watch."*
13. Click **Share**
14. Copy the invite link
15. Log out
16. Send the link to Ben in Teams

## Ben — Guest to Registered User Flow

### Phase 1: Open Invite

1. Open the invite link
2. *"This app looks useful. I should create an account."

### Phase 2: Create Account and Login

2. Click **Create Account**
3. Create an account
4. Log in

### Phase 3: Create Calendar and Event

5. Create a **"Workout"** calendar
6. Create an event titled **"Gym Session"**
7. Add description: **"Chest and Triceps"**
8. Add note: **"Get big to join the team"**
9. Create the event
10. click on the day to view the event
11. Log out

---

**Tip:** Keep narration concise and intentional. Each step is designed to highlight a specific feature or permission level (admin, member, guest).
